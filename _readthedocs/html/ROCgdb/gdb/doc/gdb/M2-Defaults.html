15.4.9.5 Modula-2 Defaults

If type and range checking are set automatically by ROCGDB, they both default to on whenever the working language changes to Modula-2. This happens regardless of whether you or ROCGDB selected the working language.

If you allow ROCGDB to set the language automatically, then entering code compiled from a file whose name ends with .mod sets the working language to Modula-2. See Having ROCGDB Infer the Source Language, for further details.
